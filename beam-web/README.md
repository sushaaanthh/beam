# B.E.A.M. Web

This package contains the React frontend for B.E.A.M. It is intentionally lightweight at this stage and serves as the presentation layer for the broader Behavioral Emotion Analysis Model platform.

## What Lives Here

- React UI for the project landing surface.
- Vite development and build tooling.
- TailwindCSS, Axios, and React Router dependencies for upcoming application work.

## Common Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```
